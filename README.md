# MBG Sentiment Analysis

## 📌 Overview
MBG Sentiment Analysis is a Natural Language Processing (NLP) project designed to analyze public sentiment from textual data related to MBG (brand/topic/service).

The goal of this project is to classify sentiments into categories such as **positive, negative, or neutral**, helping to understand user opinions and feedback at scale.

This project covers the full NLP pipeline, including text preprocessing, feature extraction, model building, and evaluation using machine learning algorithms.

---

## 🎯 Objectives
- Analyze sentiment patterns from MBG-related text data
- Classify text into sentiment categories (positive, negative, neutral)
- Compare different machine learning models for text classification
- Extract insights from sentiment distribution

---

## 📊 Dataset
The dataset consists of text data such as:
- User reviews
- Comments
- Social media posts
- Feedback related to MBG

Each data point typically includes:
- Text content
- Sentiment label (if supervised learning is used)

## 🧠 Machine Learning Models
The following models are used for sentiment classification:
- Logistic Regression
- Naive Bayes (MultinomialNB)
- Support Vector Machine (SVM)
- Random Forest Classifier

## 🔤 NLP Pipeline
1. Data Cleaning
2. Text Lowercasing
3. Removing punctuation & special characters
4. Tokenization
5. Stopword removal
6. Stemming / Lemmatization
7. Feature extraction (TF-IDF / Bag of Words)
